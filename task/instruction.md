# Qwen3.5 hybrid state transfer on GB200

Implement `/workspace/candidate.py` exporting `transfer(plan)`. Optimize complete transfer latency over the supplied Torch gather/peer-copy/scatter reference. No model weights or forward pass are involved. Read `/opt/kv-transfer/LAYOUT.md` and `/opt/kv-transfer/benchmark.py` for the exact API.

All three families are mandatory: 10 full-attention KV layers (BF16), 30 GDN convolution layers (BF16), and 30 GDN recurrent layers (FP32). The four disjoint prefill/decode TP pairs are1→1,1→2,2→1,2→2. Contexts4096,8192,32768,65536,4097,10034,32749,65521; batches1,4; contiguous, uniform-random fragmentation, and shuffled fragmented-run maps:192 cases. Source/destination page and state-slot maps change each invocation. Preserve source and unused destination memory. Copy full selected pages including explicit tail payload. TP conversion of convolution Q/K/V must split each segment independently.

Development: `python /opt/kv-transfer/benchmark.py --candidate /workspace/candidate.py --smoke --warmup 1 --samples 3 --output /workspace/smoke.jsonl` (fast in-process runner, never scored). Scored timing boundary, when `rsi-isolate` is available: `python /opt/kv-transfer/isolated_benchmark.py --candidate /workspace/candidate.py --smoke --warmup 1 --samples 3 --output /workspace/smoke-isolated.jsonl`. Full local development: remove `--smoke`. Compile only on these four allocated GPUs, MAX_JOBS16. Candidate code must be self-contained; embed CUDA/C++ in Python if needed. At most2GiB scratch/GPU; no host-staged payloads, cached answers, lossy state, model recomputation, source writes, case skipping or evaluator/result modification. Compiled execution plans may be cached by shapes/pointers, but maps/data/outputs may not. This API uses serialized calls with explicit completion synchronization; concurrent handoffs and IPC are outside scope.

Judge (protocol 0.3) runs the fixed reference and the candidate, one after the other, each in its own worker process isolated by the Harness `rsi-isolate` (no network, read-only task/candidate/runtime files, private HOME, no access to Judge memory, files or sockets). A trusted controller owns the clock, payloads, snapshots, checks and results; `transfer(plan)` sees the same plan dictionary as before, backed by dedicated GPU buffers. Timing covers a fixed controller publish of fresh source payload, the request, your transfer through all-device synchronisation and acknowledgement, and a fixed controller capture of the destination; both implementations pay the same fixed parts. 10 warmups+50 samples/case, every invocation checked; the score is the geometric mean of matched reference_median_us/candidate_median_us. All 192 cases must pass. Compile/crash/correctness/timeout/incomplete failures are unscored. Agent budget6h. Use `rsi-submit` when ready. Record hypotheses and experiments; retain the best correct candidate.

Protocol0.2 changes the scored workload to192 cases. Source/destination allocation streams and state-slot maps are independently seeded. Random layouts also jointly shuffle the logical page-pair schedule to interleave requests. Every invocation uses fresh finite BF16/FP32 bit-pattern payloads and alternates destination guard poison. Equality checks compare raw bits (including signed zero), not numeric float equality. The evaluator owns original selections/descriptors; the candidate receives private metadata copies and payload aliases. Any map/scalar/tensor-descriptor mutation invalidates the candidate. No historical128-case score is a score on this revised suite.

Candidate Python imports are limited to torch, triton and math, with the exact provided baseline adapter also allowed. Direct reflection, module monkeypatches, evaluator imports, Python evaluation/file/process APIs and known native host I/O/process APIs are rejected before import. Device code, CUDA graphs and metadata staging remain allowed. These source checks are a development contract only; scoring integrity rests on the process boundary above, which the Judge re-validates with hostile candidates before scoring.
